# ♟️ Chess

A chess game built in Unity using C# where you control your pieces directly using keyboard input.

## How It Works
Each piece is controlled in real time. You select a piece and move it using directional inputs, with number keys to choose how far to move for pieces like rooks, bishops, and queens. The board rotates each turn to keep both players oriented correctly.
